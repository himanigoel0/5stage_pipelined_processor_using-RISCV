# Simulate UART Output for RISC-V Program Output

## Objective

To simulate UART (Universal Asynchronous Receiver Transmitter) output for a RISC-V program executed on the RV32I 5-stage pipelined processor. The objective is to verify that data generated by the processor can be converted into a UART transmission frame and observed during simulation.

---

## UART Overview

UART is a serial communication protocol commonly used for communication between processors and external devices.

A standard UART frame consists of:

* 1 Start Bit (`0`)
* 8 Data Bits
* 1 Stop Bit (`1`)

UART Frame Format:

```text
| Start Bit | Data[7:0] | Stop Bit |
|     0     | 8 Bits    |     1    |
```

---

## UART Module Implementation

A simple UART transmitter module was created to generate a UART frame from an 8-bit input data value.

```verilog
assign tx_frame = {1'b1, data[7:0], 1'b0};
```

where:

* `1'b0` represents the Start Bit
* `data[7:0]` represents the transmitted byte
* `1'b1` represents the Stop Bit

The generated UART frame is available through the `tx_frame` output signal.

---

## Processor Program

The following RISC-V program was stored in Instruction Memory:

```assembly
addi x5, x0, 72
ecall
```

Machine Code:

```text
04800293
00000073
```

The instruction loads decimal value `72` into register `x5`.

ASCII value:

```text
72 = 'H'
```

---

## Data Flow

```text
Instruction Memory
        ↓
   RV32I Processor
        ↓
      x5 = 72
        ↓
    uart_data
        ↓
    UART Module
        ↓
 UART Frame Generation
        ↓
 Simulation Verification
```

---

## Simulation Results

Simulation Output:

```text
x5 = 72
uart_data = 72
tx_frame = 1010010000
```

UART Frame Breakdown:

```text
1 | 01001000 | 0
↑      ↑      ↑
Stop  Data  Start
```

Data Bits:

```text
01001000
```

Decimal Value:

```text
72
```

ASCII Character:

```text
'H'
```

---

## Verification

The processor successfully executed the RISC-V program and generated the value `72` in register `x5`.

The UART module received this value and generated the corresponding UART frame:

```text
1010010000
```

The generated frame correctly contains:

* Start Bit = 0
* Data Bits = 01001000 (ASCII 'H')
* Stop Bit = 1

Thus, UART output generation and simulation were successfully verified.

---

## Conclusion

A UART output simulation module was integrated with the RV32I 5-stage pipelined processor. The processor generated ASCII data through a RISC-V program, and the UART module converted the data into a valid UART transmission frame. The generated UART frame was successfully verified in simulation, demonstrating processor-to-UART communication.
